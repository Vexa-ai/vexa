# Community meetings

**Weekly community triage & review — every Wednesday, 14:00 UTC, 45 minutes.**

Open to anyone. The link never changes and there is no invitation — you do not need to have
contributed anything to come.

| | |
|---|---|
| **Join** | `<MEET_URL>` — quick access is on, so the link is the whole door |
| **Calendar** | subscribe to [`community.ics`](community.ics) — [raw URL](https://raw.githubusercontent.com/Vexa-ai/vexa/main/meetings/community.ics) |

| **Minutes** | one [GitHub Discussion](https://github.com/Vexa-ai/vexa/discussions) per meeting, *Announcements* category, published the same day |

## What happens

We walk the open pull requests and issues **oldest first**. Each item leaves with an owner and a
label, or it is closed. Anyone blocked on *us* — an unanswered question, a rights review, a pull
request nobody has looked at — comes before the queue.

| Minutes | Segment |
|---:|---|
| 0–3 | Since last week: what merged, released, closed. Names, not counts. |
| 3–8 | Blocked humans first. |
| 8–30 | The queue, oldest first. 90 seconds each; past that it gets `triage:needs-owner` and moves on. |
| 30–38 | Review pairing — every item walked gets a named reviewer and a named validator. |
| 38–43 | One demo, or one blocker. |
| 43–45 | Commitments, read back. |

Roles and how decisions are made: [`GOVERNANCE.md`](../GOVERNANCE.md). How to run a pull request and
what to post: [`VALIDATION.md`](../VALIDATION.md).

## The call is recorded

A Vexa bot joins every occurrence and transcribes it — the project uses its own product on its own
community. The written minutes go up the same day and **link** the transcript rather than pasting
it. [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md) applies.
