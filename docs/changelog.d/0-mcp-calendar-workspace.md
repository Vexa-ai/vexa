- **Calendar auto-join and workspaces from your own MCP client.** Four new tools on Vexa's MCP server:
  `calendar_status` (connected calendars, last sync, and which upcoming meetings the bot will join by
  itself), `calendar_connect` (the link where you connect a calendar yourself — no tool takes the feed
  address), `set_auto_join` (one meeting, one calendar, or all) and `meeting_bind_workspace` (a meeting's
  write-up lands in the workspace you name). With agents deployed, `workspace_search` finds pages by the
  words in them. Every new tool carries MCP annotations. A page written with an API key is now committed
  with `Written-by: agent`, like a worker's. See [Vexa MCP](/vexa-mcp).
