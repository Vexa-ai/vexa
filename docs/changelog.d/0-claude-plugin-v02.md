- **Claude Code plugin 0.2: no API key, and a meeting pane.** The `vexa` plugin now connects to hosted Vexa (`https://api.cloud.vexa.ai/mcp`) and signs in with OAuth, so installing it asks for nothing. It opens a Vexa pane beside the chat that shows the sign-in step, then a meeting-link field, **Send bot**, **Try a demo** and the live transcript. The pane's own calls and Vexa's read-only tools run without a prompt; `speak_in_meeting`, `stop_bot` and other meeting actions the model takes still ask. Self-hosted stacks add the server with `claude mcp add` and their key.
- **Claude Code plugin: a listener for live calls.** When one of your meetings is live, a band above the prompt offers to listen. After you press **Listen**, each new stretch of that meeting's transcript is scored by a small model against a listen brief (the same labels, focus, known, triggers, `wake_at` and `max_wait_s` the app's meeting listener uses), and Claude gets a turn with the excerpt when something matters. Claude tunes the brief per conversation (presets for sales, standups and interviews) with the `listener_configure` tool, which can change or stop the listener but never start it. The pane shows what it listens for and each time it woke Claude.
