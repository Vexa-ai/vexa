- **A shared screen's sound is transcribed in Vexa calls.** Sharing a screen in a call now asks the
  browser for its sound too (tick "Share audio" in the picker), so a video or tab shown to the call is
  heard by everyone. Vexa transcribes that sound as its own speaker, "<name> (shared screen)", and it
  feeds the live notes like any other line. Before, sharing sent video only and nothing of it reached
  the transcript. The Vexa mark's tooltip says a shared screen's sound is transcribed; an
  administrator turns it off with `CALL_TRANSCRIBE_SHARED_SCREEN=false`. See [Calls](/minutes/calls).
