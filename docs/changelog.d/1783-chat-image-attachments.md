- **Attached files show as pictures, and the agent sees them.** A pasted, dropped or picked file now
  appears in your message as a thumbnail (click for full size) or a chip with its name and size,
  instead of an "Attached files: …" line with a hashed name. They come back after a reload. The agent
  gets each file's exact path, so it no longer searches for it, and pictures are sent as images to
  Claude Code, Codex and OpenAI's API. In a shared chat, the conversation's participants see the
  files posted in it. See [Attach files to a chat](/how-to/chat-attachments).
