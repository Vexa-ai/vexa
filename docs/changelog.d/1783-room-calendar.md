- **A room's planned call goes out from your own calendar (behind `rooms` and `calendar_write`).** After planning a call, "Send from my calendar" creates the event in the creator's connected Google Calendar, with the room's call link, the agenda link and the invitees. It happens only on that click and is never done by an agent. The event is then the call's source of truth: the calendar sensor carries time changes and cancellations made in the calendar back to the planned call, and a cancelled call is kept, marked cancelled. `.ics` and Copy invite are unchanged.
