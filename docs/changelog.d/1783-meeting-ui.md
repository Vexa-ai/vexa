- **The meeting sidebar.** A meeting opens as three zones: its tools fixed on top (real name, status,
  when, how long, who; Play recording, Share, Update notes, and "…" with Delete — typed confirmation —
  and Stop bot while live; the recording player), the meeting's note in the middle, edited in place,
  with no file path, and the transcript as a bottom drawer: one line collapsed, resizable from its top
  edge (snaps, double-click toggles, height remembered), with search, live auto-scroll and
  click-a-line-to-seek. A live meeting's tab is pinned first in every chat while it runs. The note
  file opened from Files is a plain page with a "Meeting: (its name) · open" chip.
