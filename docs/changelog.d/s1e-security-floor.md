- **Untrusted triggers propose; a person decides.** A routine an agent writes is saved paused until
  you turn it on from your Routines board. Mail counts as yours only when your domain's DMARC check
  passes, and a turn an email started can only reply and propose. A room's call can no longer make
  Vexa write the workspace: it writes the call's note and proposes the rest, and anyone on the call
  from outside the workspace limits what CRM shows it. The post-meeting report no longer reads other
  attendees' personal workspaces. See
  [Security → Untrusted triggers](/security-compliance#untrusted-triggers-routines-mail-and-room-calls).
