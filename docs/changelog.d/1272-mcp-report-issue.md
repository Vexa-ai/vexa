- **New (MCP): an agent can file a ticket from inside its own session (#1272).** The `report_issue` tool lets a calling agent that hits a wall tell the operator what happened, in its own words, without leaving the session. Supplying `meeting_id` binds the report to the cluster's own record of the same meeting, so an operator reads the agent's account and the machine's account of the same seconds side by side. The caller's credential is verified before anything is filed, and the caller's API key never reaches the ticket sink — only a salted fingerprint of it. Ticketing is off until the deployment sets `VEXA_TICKET_SINK_URL`; until then the tool answers `503` and nothing else changes.
