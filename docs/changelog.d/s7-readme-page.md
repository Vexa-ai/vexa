- **The workspace page is its README, drawn for you.** With `readme_page` on, a workspace's page is
  its README with live placeholders — what waits on you, the people, rooms, routines, commitments,
  meetings, files, pins, what changed, CRM data and cards — each filled with your own access. What you
  may not see is simply absent; CRM fields only you may see are marked. README buttons (new chat,
  new room, schedule, invite, ask, run a routine) never run by themselves. Every object now has
  **Copy reference**; pasting a Vexa link makes a live chip, a meeting link offers **Send Vexa**, and
  **Share** sends a reference to a room or a person, saying in one line if someone there can't open
  it. Pins in rooms and workspaces are shared. See [Pages → The workspace page is its README](/minutes/pages#the-workspace-page-is-its-readme-readme_page).
