- **Choose the workspace new chats write to.** The chat header's "Writes to …" menu has **Make default
  for new chats**. New chats then start in that workspace; existing chats keep where they write. The
  default is kept on the server per person and checked again for every new chat: if you can no
  longer write there, the new chat writes to Personal and the workspace is not named. See
  [Workspaces](/minutes/workspaces#choose-where-new-chats-write).
