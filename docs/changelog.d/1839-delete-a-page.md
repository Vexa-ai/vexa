- **Delete a page from the page header or the navigator, with Undo.** The page header has a trash
  icon and a navigator file row has **⋯ → Delete…**, for anyone who may edit that workspace. The
  delete is a commit: the page's tabs close, links to it turn into dashed *no page yet* chips, and
  **Undo** puts it back for 10 seconds. After that, **Restore** on the removal's row in the
  workspace's History brings it back; a restore never overwrites a newer page. See
  [Pages](/minutes/pages#delete-a-page).
