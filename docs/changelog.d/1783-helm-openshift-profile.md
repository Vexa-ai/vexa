- Helm: the chart ships `values-openshift.yaml`, a profile for OpenShift restricted-v2 and multi-node clusters. It turns off the hostPath seccomp installer (Pod Security refuses it; install the profile with a MachineConfig or the Security Profiles Operator), makes the agent workspace store ReadWriteMany (name an RWX class such as CephFS), stops the chart from setting a uid, and keeps agent workers without added capabilities. With the defaults on a multi-node cluster with block storage, agent workers on other nodes wait for the workspace volume and their chats never answer.
