- **Transcript `start`/`end` units are now documented per producer (#1347).** The transcript.v1 schema and the [Meetings API](/api/meetings#speaker-attributed-transcripts) said segment times are seconds from session start, but the bot's live lanes write absolute epoch seconds while transcript import and meeting bundles write seconds from capture start. Both are described now, and wall-clock or cross-meeting use points to `absolute_start_time` / `absolute_end_time`. Documentation and schema descriptions only, no behavior change.
