- **Sharing a chat you are alone in: you choose what they see (#1783).** *Share this chat with
  @someone* shares it in place, history included, after one line from the agent naming anything
  sensitive in it. You can instead share from a point (a new chat with what was said from there on)
  or start a new empty chat with them. The person added is notified and finds the chat under Shared with me. Only the owner shares a chat's history; anyone else adding a
  person starts a new chat. Sharing a chat never gives anyone a workspace, and from the moment a
  second person joins the agent uses only what everyone in the chat can read. Adding by email
  answers the same whether or not the address has an account, and in a shared chat the agent is told
  that some workspaces are withheld without being told which.
