- **Page buttons now say exactly what they will do (#1783).** A button on a workspace page runs only
  a routine, call, card or proposal that is really yours to act on, and its confirmation names that
  thing by its real name rather than the words on the page. A routine run shows in your chat as the
  exact line sent. "Join call" only joins a call already running; anything else asks before starting
  one. Pictures and links written as HTML in a page now behave like ordinary ones: a picture from
  another site is named and offered, never loaded. "New chat" on a workspace page opens a new chat
  instead of moving the one in front.
