## Optional CRM preview in Minutes

Adds a separate CRM database/service with six MCP operations, imported source
mappings and access policies, typed custom fields, revision history, reviewed
changes and a Minutes record page. Agents can combine native meeting evidence
with mounted workspace playbooks to propose CRM changes. Flows receives durable,
idempotent record-change events through an optional pack. CRM can be omitted.

The importer preserves a tested export snapshot; arbitrary organization policy,
source automation and binary-attachment migration are not yet claimed. See
`core/crm/README.md` for deployment and import limits.
