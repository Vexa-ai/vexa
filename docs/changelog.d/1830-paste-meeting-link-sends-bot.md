- **Pasting a meeting link into a chat sends Vexa.** A chat message that is only a Google Meet,
  Teams, Zoom or Jitsi link now sends the bot every time, before the agent answers. The chat says
  whether the bot was requested, is already in that meeting (pasting the same link twice sends one
  bot), or was refused, and gives the reason. A link with other words is still an ordinary message.
  See [Paste a meeting link to send Vexa](/how-to/paste-a-meeting-link).
