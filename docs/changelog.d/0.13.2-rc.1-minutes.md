## Minutes prerelease: v0.13.2-rc.1

- Central Connections page and focused setup forms, with multi-account email/calendar, Gmail drafts,
  broker-backed Git credentials and generic secret-backed HTTPS/OAuth connections.
- Separate delegated agent MCP routing from meeting MCP, persistent timezone tools and source-read diagnostics.
- Import repositories as standalone workspaces; copy transcripts, show active chats, rename/reorder chats,
  and confirm deletion with a second click.
- New-person onboarding offers email/calendar setup and resumable research of 90 days plus relevant older threads.
- Extend entities from available private sources and the web, with citations, linked entities and coverage gaps.
- Chat tool loops continue across the 40-call boundary while retaining the whole-turn time limit.

This is a prerelease. The credential broker is currently supplied as a dogfood deployment;
standard Compose/Helm installation of the complete connections stack has not been validated.
