- **No more pages for spoken sentence openers.** After a meeting, the agent wrote a page called
  "So Vexam" from the transcript line "So Vexam, which is the Finos project". Words that open a
  spoken sentence (*So*, *And*, *But*, *Well*, *Okay*…) are now dropped from the front of a name
  before a page is written. A name one letter away from an existing page's title or alias is matched
  to that page. A name heard once in a transcript with no other source goes to the meeting's open
  questions instead of a new page. See [Pages](/minutes/pages#pages-the-agent-writes-for-names).
