- **A person's model endpoint admitted by a wildcard stays on public addresses for the whole turn.** The model proxy re-resolves such an endpoint on every request, refuses an address inside the deployment, and connects to the address it checked, so a DNS record that changes after the dispatch reaches nothing internal. An endpoint the operator names exactly in `VEXA_MODEL_BASE_URL_ALLOW` is unaffected. See [Configuration](/configuration).
- **A call's listener subscribes only to what it transcribes.** It no longer subscribes to every track in the room: microphones always, a shared screen's sound unless `CALL_TRANSCRIBE_SHARED_SCREEN=false`, and never video. With the setting off, a shared screen's sound no longer reaches Vexa at all. See [Calls](/minutes/calls).
