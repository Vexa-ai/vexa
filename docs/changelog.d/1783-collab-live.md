- **Working together in a shared chat and a shared workspace (#1783).** A message you post in a
  shared chat without addressing the agent now shows to the others within a few seconds, with your
  name, and the other person's turns with the agent appear in your chat when they finish. In a shared
  chat the agent can read the transcript of a meeting sent into a workspace everyone in the chat
  reads, and send a bot into such a meeting; private meetings stay out. A workspace member can open a
  meeting's transcript by its link. When two people or agents save the same page at once, the
  changes are merged; a change to the same lines is refused with the page as it is now, so nothing
  is lost. See [Shared chats](/minutes/shared-chats) and [Pages](/minutes/pages).
