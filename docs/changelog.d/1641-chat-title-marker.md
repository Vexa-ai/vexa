- **Chat names no longer show `<!--vexa:user-input-below-->` (#1641).** A chat started with a file or
  meeting open was named with the internal marker that separates the terminal's context from your
  message, so the chat list read `<!--vexa:user-input-below-->…`. Names
  now come from your own words only, and chats named before the fix show without the marker. See
  [Manage your chats](/how-to/chat-controls).
