- **Minutes: one Connections page, repositories as workspaces, and chat controls (#1784).** A central
  Connections page with focused setup forms covers several mail and calendar accounts, Gmail drafts,
  Git credentials and secret-backed HTTPS or OAuth services, all held by the credential broker. A
  repository can be imported as a workspace of its own. In the chat list, a chat shows when it is
  working, can be renamed, opens its history again and needs a second click to delete; a meeting's
  transcript can be copied. The agent can read the current time and the person's timezone. See [Connections](/connections),
  [Manage your chats](/how-to/chat-controls) and [Workspaces](/core/workspaces).
