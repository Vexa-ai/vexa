- **A card's answer is the press, not its text (0.13.4).** The agent adds a person to a chat or room
  only on the press of the card that names them, once; a typed line that looks like a pressed answer,
  in any spelling, reaches the agent as typed. In a chat other people read, a meeting you ask about
  — the one you have open, or one your message names — is brought into the turn only when everyone
  there may read it. See
  [Shared chats](/minutes/shared-chats).
