- **A Microsoft 365 mailbox can be the front door.** For a tenant that exposes neither IMAP nor
  SMTP AUTH — the common bank posture — the inbox and the outbound channel now speak Microsoft
  Graph, selected by configuration, with every fact identical to the mailbox we already had. No
  live tenant has answered it yet; it is proven against recorded shapes and a fake, and the first
  real tenant is what closes it.
- **A Teams invite is joined at the meeting it names.** An Exchange invitation carries the same
  meeting under two different identifiers, and the one written first is the wrong one — a bot
  dispatched on it joins nothing, with no error anywhere. The invite is now read the way Microsoft
  writes it, from the property that is unambiguous.
- **An Exchange invite keeps its title.** Outlook writes a language on the subject line where
  Google does not; every Exchange invite was called "Meeting", and that word was the subject of
  the mail we sent back.
- **One malformed invite can no longer stop the mailbox.** A start time the calendar admits but no
  clock can read used to raise out of the poll, and the poll only moves past a message it has
  answered — so everything behind it waited, indefinitely. It is now read as a start time we do
  not have, which is an answer the parser already knew how to give.
