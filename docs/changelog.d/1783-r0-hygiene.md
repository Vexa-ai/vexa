- **Feature switches fail closed in the app.** The app shows a switched feature only when the server answers it on; a switch the server does not name stays hidden. Every switch the app reads is registered server-side, checked by a test.
- **Model calls are priced at market.** A call whose provider reports no cost is counted at its model's price from OpenRouter's public price table (read daily, cached), or from a snapshot bundled with the release; the flat $15/$75 per million tokens is gone. `llm_price_*` now prices only a model no table names. `VEXA_MODEL_PRICES_URL=off` keeps an air-gapped install off the network.
- **One usage ledger.** agent-api's spend ledger is the one writer of model usage; the rolling-day token budgets read a view of the same record, and agent-api's own model calls (home, titles, summaries) are counted in dollars too.
