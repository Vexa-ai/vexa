- **A new chat starts on the model and effort you picked last.** Every pick in a chat's model
  picker is also your default for new chats, on every device: agent-api keeps it per person, on the
  server. A chat keeps the model and effort it was last used with, so a pick elsewhere does not move
  it. A remembered model the catalog no longer offers you, or an effort the model no longer offers,
  is skipped without a message: the picker shows the default that applies and the turn runs on it.
  See [Model catalog](/model-catalog#what-people-see).
