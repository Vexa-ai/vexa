CRM records open as document-style cards with key facts, Markdown narrative,
formatted values and linked record names. Technical fields stay available under
All fields. Administrators can configure sections, labels, ordering and formats
through `crm_configure`; layouts are versioned independently of record data and
respect the reader's field permissions. Apply the optional CRM migration and
SELECT/INSERT grants for `crm_card_layouts` before deploying this update.
