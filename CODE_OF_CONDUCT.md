# Code of Conduct

Vexa follows the [FINOS Community Code of Conduct](https://www.finos.org/code-of-conduct),
which is based on the [Linux Foundation Code of Conduct](https://lfprojects.org/policies/code-of-conduct/).

We are committed to providing a friendly, safe and welcoming environment for all,
regardless of background or identity.

This applies everywhere the project happens: this repository, our
[Discord](https://discord.gg/Ga9duGkVz9), and the weekly community meeting —
which is open to anyone, recorded, and transcribed, with minutes published in
[`meetings/`](meetings/).

Please report any unacceptable behavior to [help@finos.org](mailto:help@finos.org)
or to a maintainer listed in [`MAINTAINERS.md`](MAINTAINERS.md).
