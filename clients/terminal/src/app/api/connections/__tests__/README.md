# Connections route tests

`assertion.test.ts` holds the TypeScript signer to the contract's golden vectors (shared with the
Python signer) and its refusals; `broker.test.ts` the signed human-role request and its typed
faults; `routes.test.ts` the closed route table, origin check and callback; `config.test.ts` the
declared keys against compose and the chart, and compose's human-key isolation.
