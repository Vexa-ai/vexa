# minutes/ — the one-object shell

Minutes mode's frame (#1311): everything is a room — a page (right), a conversation (center), a
context (mount set, named in the header), a flavor. Meetings are rooms that happened. Two rail
lenses (Meetings by time, Rooms by name) sort one set; every row opens the same screen. Replaces
the dockview Workbench in minutes mode only.
