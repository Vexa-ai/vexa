# workspace

Skill `vexa-workspace`: how Claude keeps a Vexa workspace (or the local ~/Vexa folder) current — read the workspace's own rules first, search before writing, `entity_upsert` people/companies/decisions with sources, the meeting page after a call, one line back in chat; never personal talk or secrets. Default conventions come from the workspace template's `CLAUDE.md` (`behavior/workspaces/default`). See `SKILL.md`.
