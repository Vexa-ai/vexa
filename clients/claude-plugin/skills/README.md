# skills

- `listen/` — `vexa-listen`: open the panel first, start vexa-link once per chat, set the listener
  profile for each call, and what to do with what reaches the chat.
- `workspace/` — `workspace`: reading the workspace before a call; linked cards and the meeting's page
  as the live report, in small updates that never touch what the person wrote.
- `setup/` — `setup`: the one-chat install — pair with the code the person brought, sign in in their own browser, and Vexa's tools appear in the same chat through the plugin.
