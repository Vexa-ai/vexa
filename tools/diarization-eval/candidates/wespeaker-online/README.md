Standalone CPU WAV-to-RTTM CLI, derived from the June diarizer at `b0424b695` (2026-06-11), removed from the product in `805084073`; source provenance is that history and the seeded read-only refs. Carries local copies of diarizer, clustering, segmenter and metrics, with all executable thresholds/defaults unchanged; threshold and gate explanations are retained verbatim from the seeded June sources.
`run.sh` resolves the repo from its own location, links the seeded mixed-pipeline node_modules beside main.ts, and runs its tsx with the local tsconfig. Root tsc checks the same dependency through baseUrl/paths; this is dependency resolution only, with no imports from product source and no package/lockfile changes.
`main.ts` reads PCM16 WAV, feeds 20 ms Float32 chunks with audio-time timestamps, records committed turns, flushes buffered speech at EOF, applies commit/cluster rewrites and clips times to the WAV. Adaptations explicitly select CPU and propagate inference failures to exit 2 and exit 0 after the RTTM write completes; no model or clustering tuning. The single committed speaker per turn is preserved, including on overlap segments; no extra overlap speaker is invented.
`run.sh --help` requires no model; model-loading WAV runs download WeSpeaker ResNet34-LM and pyannote segmentation through transformers.js into the system temporary directory's `diarization-eval-models` cache. All model-loading execution and real-model DER are caller-verified outside the sandbox.

Resolution: `run.sh` links the mixed-pipeline module's `node_modules` beside `main.ts` (gitignored) because Node's ESM resolver ignores `NODE_PATH`; a missing module directory is a named exit 2, not a resolution error mid-run.

Input is normalized once over the whole WAV to −26 dBFS RMS in Float32 before the pipeline. Silence stays unchanged; samples are not clipped. `--no-gain` disables normalization. The applied gain in dB goes to stderr. `run.sh <input.wav> <output.rttm> --dry-gain` reports gain and exits 0 before any model import or download, without writing RTTM; it also accepts `--no-gain`.

`DIAR_THREADS=<positive integer>` sets both ONNX `intraOpNumThreads` and `interOpNumThreads` on the WeSpeaker and pyannote sessions through transformers.js `session_options`; unset leaves library defaults. `DIAR_NEW_SPEAKER_THRESHOLD=<cosine distance 0..2>` overrides the clustering threshold; unset preserves the June executable default of `0.45`. All other tuned constants stay unchanged. `run.sh` inherits these environment variables.
