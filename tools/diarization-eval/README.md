# Diarization evaluation (development only)
`python -m diarization_eval --fixtures <dir> --candidate <name> [--collar <s>] [--skip-overlap] [--json <path>] [--limit <n>] [--timeout <s>]` runs from this directory; its contract lives in [`diarization_eval/__main__.py`](diarization_eval/__main__.py). Fixture pairs are `<name>.wav` (16 kHz mono PCM16) + `<name>.rttm`; incomplete pairs warn and skip. Each `candidates/<name>/run.sh <input.wav> <output.rttm>` writes one RTTM with the fixture name; the runner exports `PYTHON` and `DIAR_REF_RTTM`. Exit 0 means all complete fixtures scored; any candidate/fixture failure returns 2 while retaining successful rows. `--timeout` limits each candidate to 1800 seconds by default; CLI overrides `DIAR_CANDIDATE_TIMEOUT_S`. A timeout kills the candidate process group, reports the fixture as failed, continues the sweep, and exits 2. `--limit` selects the first N complete pairs in sorted name order.
Columns: `file  DER  miss  fa  conf  ref_spk  hyp_spk  cand_s  audio_s`. DER is a fraction; miss/fa/conf are speaker-seconds from pyannote.metrics. `ALL` uses `abs(metric)` (corpus DER), sums speaker counts and times across successful files, and takes the maximum child peak RSS. JSON is a list of the same rows plus `candidate`, `collar`, `skip_overlap`, `peak_rss_mb` (MiB, null if unavailable); each candidate's child RSS is measured in a fresh helper process. Scoring uses pyannote's default union of reference/hypothesis extents. `--collar` is pyannote's total collar width, ±collar/2 around every reference boundary. Defaults: collar 0, overlap included.
Use a Python environment with pyannote.metrics 4.1 (including pyannote.core) and pytest; no torch or pyannote.audio. Run `python -m pytest -q`; generate model-free silence fixtures with `python -m diarization_eval.synth --out ../../.claude/scratch/fx`. `ref` and `permute` read the reference; `single` labels the full WAV with one speaker. Keep generated fixtures and reports in a temporary or gitignored directory. Nothing here is a service dependency.
`./fetch_ami.sh --out ../../.claude/scratch/ami --subset dev --mic Array1-01 --limit 2` fetches AMI single-distant-microphone fixtures (test subset also supported); requires curl and ffmpeg or sox. Existing WAVs are refused unless `--force` is supplied; fixture stems remain meeting IDs for RTTM alignment. AMI downloads and every model-loading run of `wespeaker-online` are caller-verified outside the sandbox. See the candidate README for the June source provenance, dependency resolution, and cache location; no fixtures or models are committed.

Repeat `--candidate-env KEY=VALUE` to forward environment overrides to a candidate (last value wins). For example, add `--candidate-env DIAR_THREADS=2`. The harness timeout still follows `--timeout` > inherited `DIAR_CANDIDATE_TIMEOUT_S` > 1800 seconds.

`python -m diarization_eval sweep --fixtures <dir> --candidate wespeaker-online --env DIAR_NEW_SPEAKER_THRESHOLD=0.40,0.45,0.50 --candidate-env DIAR_THREADS=2 [--json out.json] [--collar <s>] [--skip-overlap]` evaluates every fixture once per value in the given order. Each row aggregates successful files for that value: exactly `value DER miss fa conf files`, with no `ALL` row. JSON has the same six keys. DER is accumulated over the corpus, and `files` counts successful fixtures; any failure returns 2 after continuing remaining runs. The swept value takes precedence over `--candidate-env` for its key.

`python -m diarization_eval.synth --out <dir> --level-dbfs -50 --duration 5` creates a 5-second 16 kHz mono PCM16 440 Hz sine (`sine.wav` plus RTTM); level means RMS dBFS. Omitting `--level-dbfs` keeps the two silent 20-second fixtures. `fetch_ami.sh --limit N` chooses the first meeting from each of N distinct letter-prefix groups in list order; without a limit all meetings are selected. `bash test_fetch_ami.sh` tests selection without downloads.
