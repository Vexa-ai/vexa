## Triagers

Triagers hold GitHub `triage` permission: labels, assignees, milestones, closing and reopening
issues, marking duplicates, requesting reviews. **Not merge, not push.** Their approving reviews
count as the peer review in the merge rule.

## Updating this file

All changes to the maintainer and triager lists are managed openly:

- **Submit a Pull Request** to this file for any addition, removal, or update.
- **If the project's governance requires a vote**, document or link to the vote outcome in the PR
  description or comments. Triager admissions are decided at the weekly community meeting; link the
  minutes.
- This process creates a public audit trail of project leadership over time.

Please email **help@finos.org** whenever this file is updated with a change to maintainership.
