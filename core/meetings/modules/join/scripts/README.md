# join/scripts — gate + debug tooling

- `check-isolation.js` — gate:isolation (P2): walks `src/` and fails if any import escapes the package (not a Node builtin, declared dep, or intra-package path).
- `debug-join.ts` — the live join harness: launches a stealth browser (`playwright-extra`) and runs `joinMeeting` against a real `MEETING_URL`. Run via `tsx` (not compiled / not a published `bin`).
- `debug-rate.sh` — throttle / failure-mode driver (many joins, dialed gap) for admission testing.
- `docker-entrypoint.sh` — entrypoint for the `Dockerfile.debug` hot-reload + noVNC container.
- `platform-meetings.ts` — creates and deletes a real meeting per platform with the test accounts (#1970). Operator tool; runs via `tsx`.
  - `tsx scripts/platform-meetings.ts create <google_meet|zoom|teams>` prints a receipt; `tsx scripts/platform-meetings.ts delete <receipt.json>` deletes, verifies and prints the receipt with `deleted` filled (exit 1 if not deleted). `--dry-run` prints the planned requests and the receipt shape, needs no credentials.
  - Inputs: `VERIFY_SECRETS` (default `~/vexa-test-rig/secrets.env`, outside the repo): `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN`; `ZOOM_ACCOUNT_ID`, `ZOOM_CLIENT_ID`, `ZOOM_CLIENT_SECRET` (Server-to-Server OAuth); `MS_TENANT_ID`, `MS_CLIENT_ID`, `MS_REFRESH_TOKEN`, optional `MS_CLIENT_SECRET` (delegated, `OnlineMeetings.ReadWrite`). These are harness inputs, not product settings; tokens are never printed.
  - Receipt: `platform`, `platform_meeting_id` (Calendar event id / Zoom id / Graph id), `native_meeting_id` (Meet code / Zoom id / Teams join id), `meeting_url` (query stripped, so no passcode), `space` (Meet only), `created_at`, and after delete `deleted {at, delete_status, verify_status, note}`. A meeting counts as deleted (`platform_meeting_deleted`) only when `delete_status` is 2xx and `verify_status` is 404/410.
  - Meet: the meeting is a Calendar event with a Meet conference, opened with `spaces.patch accessType=OPEN`. Google has no delete for a Meet space: delete ends the active conference and deletes the event; a `cancelled` event counts as 410 and `note` says `space persists; conference ended (<status>), event cancelled`.
