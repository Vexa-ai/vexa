# Mixed-lane hallucination phrases — the MEDIA-ARTIFACT family only.
#
# Provenance: this is a SUBSET of the gmeet lane's phrase files
# (../../../gmeet-pipeline/src/hallucinations/*.txt), selected by one rule: a line stays only
# if it cannot plausibly be said in a meeting. hallucinations-are-subset.test.ts pins the
# subset property against those files.
#
# Why not the whole list. Measured on the m24 Teams tape (95 published rows, real STT): the
# gmeet en list would suppress "Yeah." and "I don't know." — both real speech from a real
# meeting. The gmeet lane can afford that (it is per-channel and re-derives), the mixed lane
# cannot: a suppressed row is speech deleted from a one-shot mixed stream. So the mixed lane
# takes only the outro/subtitle-credit family, which no participant utters.
#
# Lines beginning with `re:` are case-insensitive regexes — the credit strings arrive in
# endless variants ("Субтитры сделал X", "Добавил субтитры X", "Редактор субтитров …"), and
# an exact list loses to every new one. JS \b is ASCII-only, so Cyrillic patterns end in
# (\s|$) rather than \b. Everything else is an exact match, punctuation-
# normalised, exactly as the gmeet filter matches.
